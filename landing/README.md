# Archived PlayCounter landing site

This directory is preserved only as upstream PlayCounter history. It is not the
LudusAtlas website and must not be used to publish or distribute LudusAtlas.

The previous Azure Static Web Apps workflow has been removed. The related tools
under `scripts/landing-seo/` fail closed unless an explicit archival-maintenance
environment flag is provided. Links and PlayCounter product language in this
directory refer to the upstream project, not to LudusAtlas releases.
